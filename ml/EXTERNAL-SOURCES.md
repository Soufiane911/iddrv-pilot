# Sources externes de veille

Les pièces de veille plasturgie citées par la documentation HDT ne sont pas
embarquées dans ce checkout. Elles ne constituent donc pas des preuves
consultables par les tests ou le runtime.

La copie de référence utilisée pour la rédaction est conservée dans l'historique
Git du dépôt, à l'empreinte immuable suivante :

- dépôt : `https://github.com/Soufiane911/iddrv-pilot`
- commit : `feadef7268cb87a16228be254e0e786aa0f55d63`
- sous-répertoire : `source-plasturgie/`
- URL d'archive : `https://github.com/Soufiane911/iddrv-pilot/tree/feadef7268cb87a16228be254e0e786aa0f55d63/source-plasturgie`

Cette référence externe versionne notamment les versions EUROMAP 77 Release
1.01 et EUROMAP 83 Release 1.03 ainsi que l'index de veille et sa matrice de
liens entre signaux et défauts. Sa disponibilité distante n'est pas garantie
par le build local ; toute certification doit donc vérifier l'empreinte et
l'accès à cette référence avant de la citer comme preuve.
