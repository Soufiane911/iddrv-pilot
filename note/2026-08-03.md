## Démarche ML / IA actée aujourd’hui (fil rouge certif bloc 2)

### Idée centrale

Faire une **veille IA ciblée** pour choisir un modèle de **prédiction de risque de rebut**, puis le **paramétrer / évaluer / (optionnellement) exposer**, afin de sécuriser E2 + E3 sans remplacer le moteur déterministe du pilote.

```text
Veille (C6)
  → benchmark services/modèles (C7)
  → paramétrage modèle retenu (C8)
  → API / intégration (C9–C10)
  → monitorage + tests + livraison (C11–C13)
```

### Pourquoi ce sujet (rebut) et pas un LLM/RAG

| Critère | Prédiction rebut tabulaire | LLM / RAG |
|---|---|---|
| Alignement données IDDRV | Fort (cycles, qualité, scrap) | Faible sans corpus procédures |
| On-prem / confidentialité | Oui | Risqué si cloud |
| Explicabilité atelier | Moyenne à bonne (arbres/logreg) | Faible pour un score rebut |
| Coût | Nul (sklearn local) | Élevé |
| Hallucination | Non | Oui |
| Vocabulaire RNCP « modèle » | Oui (artefact + train/eval) | Oui mais hors cadrage projet |

**Décision :** LLM/RAG = écartés pour le pilote (rester dans la veille comme options non retenues).  
**Retenu pour implémentation :** baseline sklearn de risque de rebut + déterministe inchangé en investigation.

### Architecture cible (oral jury)

```text
Données atelier (cycles, qualité, ERP)
        │
        ▼
┌──────────────────────────┐
│ Score risque rebut (ML)  │  ← sklearn, artefact versionné
│ probabilité 0–1 + seuil  │
└────────────┬─────────────┘
             │
             ▼
┌──────────────────────────┐
│ Investigation            │  ← DeterministicInvestigator
│ hypothèses + preuves     │     (pilote actuel, inchangé)
└────────────┬─────────────┘
             │
             ▼
      UI atelier / incident
```

Phrase orale de référence :

> « Le ML anticipe le risque de rebut. Le déterministe explique la cause avec des preuves. Pas de LLM en pilote : confidentialité, coût, hallucinations. »

### Étapes de la démarche (ordre de bataille)

#### Phase 2 — Benchmark & préconisation (C7)
Tableau minimal à remplir avec preuves chiffrées quand possible :

| Approche | Explicabilité | On-prem | Données | Coût | Résultat attendu IDDRV |
|---|---|---|---|---|---|
| Règles déterministes | ★★★★★ | Oui | Faible | Nul | Investigation + fallback (déjà en prod pilote) |
| Régression logistique | ★★★★ | Oui | Moyen | Nul | Baseline probabiliste rebut |
| Random Forest / GBDT | ★★★ | Oui | Moyen | Nul | **Candidat principal score risque** |
