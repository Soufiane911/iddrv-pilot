# Dossier preuves du rapport DEVIA

Chaque épreuve a son sous-dossier. On y dépose **au fil de l'eau** les captures,
fiches, exports et journaux cités dans le rapport.

## Règles

- Nommer les fichiers avec un préfixe de date : `2026-08-07-capture-import.png`.
- Ne jamais y déposer de secrets, identifiants ou logs bruts non anonymisés.
- Les fichiers cités dans le rapport doivent exister ici (ou pointer vers le repo).
- Le `README.md` de chaque sous-dossier est la checklist : cocher au fur et à mesure.

## Sous-dossiers

| Dossier | Épreuve | Contenu principal |
|---|---|---|
| `E1/` | Données (C1–C5) | captures import/profilage, note RGPD, volumes vérifiés |
| `E2/` | Veille et choix IA (C6–C8) | journal de veille daté, benchmark, métriques HDT |
| `E3/` | Service IA (C9–C13) | capture API, capture panneau UI, preuve CI locale |
| `E4/` | Application (C14–C19) | captures parcours UI, schéma archi, preuve CI locale |
| `E5/` | Monitorage et incident (C20–C21) | fiche incident, captures quarantaine, logs anonymisés |
| `transversal/` | Toutes | captures partagées, vidéos de secours démo orale |
